- basic revision
	- **Validity** refers to whether an experiment or investigation is in fact testing the set hypothesis and aims. Is the investigation obtaining data that is relevant to the question?
	- **Reliability** refers to the notion that if the experiment is repeated many times, the results obtained should be consistent.
		- improve

	- **Accuracy** is the ability to obtain the correct measurement. To obtain accurate results, you must minimise systematic errors.
	- **Precision** is the ability to consistently obtain the same measurement. To obtain precise results, you must minimise random errors.
	- **Uncertainty** is how far an experimental quantity might be from the true value.

## errors
- A **systematic error** will cause the measured error to always be above, or always below, the true value. It is an error that it will occur again if the investigation is repeated in the same way.
- **Random errors** occur in an unpredictable manner and are generally small. They could give a value higher, or one that is lower than the true value. Whenever a measuring device is used, whether it is a burette or an electric balance, random error will occur.
